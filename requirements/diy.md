> 定位：把 RAW 解码器底层控制项从数字滑块 / 文本矩阵，改造为可视化空间图形交互；图形交互作为操作代理，底层复用现有浮点管线；图形视图与高级数值面板双向同步；核心目标：降低相机色彩标定、自定义解码实验的上手门槛。
> 前置约束：
> 
> 
> 1. 所有可视化操作作用于**线性 RAW 解码管线（色调映射、上层调色之前）**，不改动上层调色模块；
> 2. 启用【LR 联合 AI 降噪 + Demosaic】模式时，本模块中和 AI 冲突的调节面板自动隐藏、置灰禁用；
> 3. 交互预览统一复用现有低分辨率预览管线，保证拖动流畅；全尺寸计算仅在保存标定、导出中间帧触发；
> 4. 增加参数合法性校验，对矩阵奇异、数值溢出、色彩反转等风险做软钳位 + 友好提示，防止管线崩坏；
> 5. 图形模式 / 高级数值编辑模式双向同步，随时切换。

## 1. 拜耳传感器底层参数可视化视图

### 1.1 四通道拜耳线性直方图视图

1. 视图独立绘制 R / G1 / G2 / B 四路传感器原始线性直方图，不做 Gamma 校正；
2. 交互：直方图左右侧拖拽独立游标，分别控制**分通道黑电平**、**饱和白电平裁切阈值**；
3. 视觉标记：高亮显示被黑电平切除的暗部区域、被饱和电平裁切的高光像素；
4. 扩展能力：支持载入暗帧，在直方图上叠加噪声底参考线，直观判断暗噪声地板；
5. 联动：修改图形游标，同步更新高级面板内四个通道的数值；修改数值，直方图游标自动对齐。

## 2. 白平衡可视化标定视图

### 2.1 CIE 1931 xy 色度图白点视图

1. 画布渲染马蹄形 CIE xy 色度轮廓，标注 D50、D65 标准白点标记；叠加当前目标工作空间色域轮廓；
2. 交互：拖拽圆点自定义目标白点；画面吸管取中性灰，自动打点并换算白平衡增益；
3. 配套时序切换：视图旁提供时序选择开关（复用已有管线）
   - 时序 A：拜耳域白平衡（CCM 之前）
   - 时序 B：XYZ 域白平衡（Demosaic+CCM 之后）
   - 切换时序弹出提示：管线顺序变更，色彩结果会变化；
4. 联动：白点位置变更，自动同步 R/G/B 白平衡增益数值面板。

## 3. CCM 相机色彩矩阵可视化标定（核心功能）

两套视图共存，可切换，共享同一套 3×3 CCM 数据

### 3.1 24 色卡标定视图（优先实现）

1. 双列布局：左侧固定标准 24 色卡参考色块，右侧实时渲染当前解码输出色块，色块之间绘制连线映射关系；
2. 交互：直接拖动输出色块向参考色块对齐；拖动完成后台使用最小二乘求解新 CCM；
3. 权重控制：每个色块支持单独勾选启用 / 关闭拟合权重；内置快捷预设「优先保护肤色色块组」；
4. 采样：支持在打开的 RAW 画面上框选 24 色卡区域，自动采样色块初始值；
5. 联动：色块对齐更新矩阵后，高级矩阵面板 9 个数值自动刷新；手动修改矩阵，色卡视图色块同步刷新。

### 3.2 色域三角进阶视图（高阶，可选后序开发）

1. 在 xy 色度图内绘制两套 RGB 三角形：相机原生基色三角、目标工作空间三角；
2. 交互：拖拽三角顶点调整基色，实时更新转换矩阵；后台实时校验矩阵条件数，顶点不允许拖到造成矩阵退化的区域；
3. 用途：适合研究色域拉伸、基色偏移，面向深度色彩实验用户。

## 4. 管线拓扑流程图可视化

1. 横向节点式流水线视图，节点清单：原始拜耳、黑电平校正、白平衡、拜耳降噪、Demosaic、CCM、色散校正、色彩空间转换；
2. 交互规则：
   - 支持拖拽节点调整先后顺序；逻辑非法、冲突的放置位置自动置灰，禁止放置；
   - 点击任意节点，自动唤起该节点对应的可视化面板（如点击白平衡节点，弹出色度白点图）；
3. 预设能力：整套节点顺序 + 所有配套参数，打包保存 / 加载为【解码方案预设】；
4. 互斥逻辑：选中「联合 AI 降噪 + Demosaic」节点，自动旁路、置灰独立拜耳降噪、独立 Demosaic 节点，视图上不可操作。

## 5. Demosaic 去拜耳、伪色 / 摩尔纹抑制可视化视图

1. 局部放大对比面板：支持在预览图上框选局部区域（树枝、织物、栅栏等高伪色区域）放大观察；
2. 边缘掩码叠加预览：半透明掩码叠加在放大图上；红色 = 算法判定边缘区、绿色 = 平滑插值区；
3. 交互：拖拽边缘判定阈值游标，掩码实时刷新，联动伪色抑制强度；
4. 进阶笔刷工具：涂抹画面区域，强制标记为【边缘保护区】或【强伪色压制区】，实现空间局部差异化插值策略；
5. 算法下拉：AHD / VNG / 双线性 / AI 联合 Demosaic（互斥）。

## 6. 镜头校正可视化视图（色散彩边）

1. 局部放大视图，聚焦画面边缘彩边区域；视图标记轴向色散、横向色散的色彩偏移；
2. 交互：拖动校正强度游标，实时预览彩边消除效果；

> 
> 暗角、畸变基础校正逻辑已有，本迭代仅增加彩边可视化预览交互。

## 7. 配套导出能力（本模块专属）

1. 支持导出当前标定方案：CCM 矩阵、白点参数、黑电平、管线拓扑、降噪校正参数，输出独立 JSON 标定文件；
2. 支持导入外部 JSON 标定配置，导入后所有图形视图、数值面板自动同步更新；
3. 支持从 DCP 配置提取 CCM，加载进可视化标定视图。

## 8. 验收标准（本模块专属）

1. 四通道拜耳直方图、CIE 白点色度图、24 色卡标定视图、管线流程图可正常打开，图形操作与数值面板双向同步；
2. 管线节点拖拽可调整时序，非法时序拦截、AI 模式自动旁路相关调节面板；
3. Demosaic 边缘掩码实时反馈，笔刷局部控制伪色抑制生效；
4. 参数越界、矩阵退化场景有校验、软钳位、提示，不会造成渲染崩溃；
5. 所有图形交互拖动时使用低分辨率预览，操作流畅；保存标定、导出中间帧执行全尺寸管线计算；
6. 标定配置导入导出正常，跨会话可复用用户自定义色彩科学方案。
