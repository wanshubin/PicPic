# 选图 & 二次构图辅助模块需求（直接放进你的 PRD，独立章节，不打乱原有 RAW 管线）

> 
> 模块定位：独立辅助工作流模块，**不侵入 RAW 解码调色管线**，和调色面板并行；支持浏览筛选源文件、分拣到目标文件夹、二次构图辅助。
> 适用：挑片、初选、定构图，和你主功能「色彩还原、调光调色」分开。

## 一、基础功能：源 / 目标目录分拣（核心）

1. 目录配置
   - 两个路径选择器：**源目录**、**目标目录**，支持手动输入路径、文件夹弹窗选择；记录上次打开的路径，软件重启自动恢复。
   - 支持记忆多组常用目录对，下拉快速切换（可选，非 MVP 强制）。
   - 源目录扫描：自动遍历目录下支持的 RAW 格式（和主解码器一致：ARW/CR3/NEF/DNG 等）+ JPG；**不递归子文件夹（可加开关开启递归）**
   - 文件列表：缩略图网格，显示文件名、拍摄时间、相机型号；缩略图优先复用软件自身预览管线（低分辨率预览）。
2. 图片浏览
   - 浏览模式：方向键 / 鼠标滚轮切换上一张、下一张；支持键盘快捷键。
   - 当前图片信息栏：文件名、格式、尺寸、EXIF（焦距、光圈、快门 ISO）。
3. 分拣动作
   - 选中当前图片，执行【复制到目标目录】：**复制，不是移动**，源文件保留；同名文件增加序号后缀避免覆盖。
   - 附加动作：
     - 复制 + 下一张：一键复制并自动切下一张，适合高速挑片
     - 标记拒绝：仅本地标记，不复制，红色标记缩略图，方便后续批量清理
     - 星标评分（1~5 星）：写入文件侧 carrier（独立 json，不修改原 RAW），缩略图显示星级
   - 批量操作：多选多张缩略图，批量复制到目标目录
4. 安全约束
   - 禁止覆盖源文件；复制前校验目标路径写入权限，无权限弹出提示
   - 分拣日志：简单日志，记录什么时候复制了哪些文件，可查看
   - 过滤开关：只看 RAW / 只看 JPG / 全部

## 二、预览模式：固定视野构图辅助（你提的核心功能）

> 
> 名称：构图框模式 / 固定视野模式

1. 开关：预览面板顶部独立开关「固定视野构图」，开启后生效，不改动原图渲染、不修改色彩管线。
2. 高亮构图框设置
   - 框在画布正中央，**固定比例高亮区域**；外层画面半透明暗化压暗，突出中间区域
   - 预设比例列表，可自定义：
     - 3:2（单反原生）、4:3、16:9、1:1 正方形、2.39:1 电影宽幅
   - 支持自定义宽高比输入（例如 1.85:1）
   - 样式可调：高亮框边线颜色、粗细；外部暗角透明度（0~80%）
3. 交互逻辑
   - 图片可以独立拖动、缩放（鼠标拖拽平移，滚轮缩放）
   - 构图框**位置大小永远固定居中不动**；动的只有底层图片
   - 用途：把画面里想要的主体挪进框内，快速评估二次构图裁切效果，**不会修改原图、不会生成裁切文件**，仅预览辅助
   - 快捷键：一键切换构图比例、一键开关暗化遮罩
4. 附加构图辅助线（可选）
   - 三分线、黄金螺旋、居中十字线，可单独开关，叠加在高亮框内部

## 三、配套推荐选图相关功能（同模块，按需加入，分 MVP / 进阶）

### ✅ MVP 必做（上面两大块之外）

1. 筛选：按星级、标记（接受 / 拒绝）筛选列表，快速只看打星图片
2. 缩略图排序：文件名、拍摄时间（EXIF 时间）、文件大小
3. 快速旋转预览：仅预览旋转，不写入文件（评估竖横构图）
4. 全屏预览模式：去掉侧边面板，更大画布看构图

### ✅ 进阶（做完基础再迭代）

1. 多目标文件夹：不止一个目标目录，下拉可以选择 A/B/C/D 不同分拣文件夹，适合分 “保留 / 精修 / 废片 / 朋友圈”
2. 批量重命名：复制到目标目录时，支持模板重命名（日期 + 序号）
3. 对比模式：左右并排，当前图和上一张对比挑片
4. 颜色标签（红黄绿蓝），和星级分开，标记不同用途
5. 导出分拣清单：导出 csv，记录源路径、目标路径、星级、标签
6. 自动同步：目标目录变更刷新；源目录文件变化自动刷新列表（加防抖，不要频繁扫描）
7. 裁切预设导出：构图框内区域，直接导出 JPG 小样（仅导出，不碰原始 RAW）

## 五、边界约束（非常重要，避免和主 RAW 调色模块耦合）

1. 本模块所有标记、星级、标签**不写入 RAW/EXIF 本体**，存在图片同目录下 `.yoursoftware.pick.json`，防止破坏原始文件；可选 “导出标签到 EXIF” 作为进阶功能。
2. 构图框只是视觉预览层，叠加在渲染结果之上，**不参与色彩管线计算，不输出裁切 RAW**。
3. 缩略图和预览服用同一个低分辨率预览管线（和你之前约定：拖动预览走降采样管线），保证性能一致。
4. 复制动作是操作系统层面文件复制，不做 RAW 转码，原样搬运
