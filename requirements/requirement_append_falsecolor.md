## 边缘伪色、色散、高光彩边完整校正模块
目标：系统性修复四类问题：CMOS像素串扰、解拜耳插值伪色(False Color)、镜头横向(LCA)/轴向(Loca)色散、高光通道非同步饱和溢出带来的彩色边缘、光斑彩边。所有校正在线性传感器域执行，在白平衡、CCM色彩映射之前，与机型色彩标定逻辑解耦。
管线顺序：
RAW读取 → CMOS串扰补偿 → Demosaic（AMaZE/LMMSE + FBDD） → 高光Roll-off软饱和压缩 → LCA横向色差校正 → LoCA轴向色散校正 → 边缘导向伪色抑制 → 白平衡缩放 → CCM色彩映射。

### 功能明细
1. CMOS串扰补偿
3×3解耦矩阵，用于补偿BSI/堆栈CMOS像素间光子渗漏串扰；参数随机型标定文件配置；提供【串扰补偿强度 0~1】滑块与独立开关，默认开启。标定视图自动关闭。
2. Demosaic 基础伪色抑制
默认使用AMaZE，高质量导出可选LMMSE；提供算法下拉选择；FBDD降噪伪色抑制强度0~1可调，默认0.6。VNG仅作为测试选项。
3. 高光软饱和Roll-off压缩
在线性域实现拐点平滑压缩，避免RGB通道不同步饱和溢出；参数包含高光拐点、压缩坡度，随机型配置；独立开关。
4. 横向色差 LCA校正
以G通道为基准，R/B通道亚像素缩放校正，支持径向强度渐变（四角增强）；参数：红缩放、蓝缩放、径向增强；可保存至镜头配置文件。独立开关。
5. 轴向色散 LoCA校正
基于DoG高光光斑掩码，针对焦外散景、点光源光斑做分通道色散衰减；控制强度、光斑阈值；独立开关，默认0.4。
6. 边缘导向伪色抑制（核心收尾）
绿色通道梯度生成边缘掩码；仅在高对比度边缘，对R/B通道做小半径中值平滑，G通道保持不变，保护细节；参数：抑制强度、边缘敏感度；独立开关，默认0.5。平坦区域不做平滑，避免抹除原生彩色。

### 参数体系
参数优先级：用户实时参数 > 镜头配置 > 机型默认配置 > 全局默认；机型CCM json附带一套推荐校正参数；镜头单独支持独立配置文件。
### 视图联动
- 观感预览（默认）：全部校正模块启用，加载默认参数
- 线性标定视图：一键全部关闭校正模块，输出原生解拜耳线性数据，用于CCM比对、色彩标定
### 渲染一致性
低分辨率拖动预览、全尺寸导出复用同一套校正逻辑与参数，滤波半径按分辨率自适应缩放，保证预览、导出观感一致。
### 约束
所有校正模块支持独立开关；校正仅在线性传感器RGB空间执行；不处理摩尔纹混叠；饱和死白区域仅能抑制彩边，无法恢复丢失色彩信息。
