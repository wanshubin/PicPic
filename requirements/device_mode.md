## 1. 能力定义

设备模拟：对最终送到屏幕上的预览图像施加一组可调节的偏差变换，模拟目标显示设备的固有缺陷 / 风格倾向：亮度偏移、对比度、饱和度衰减 / 增强、色偏（RGB 增益偏移）、灰度（去色）、伽马偏移。
典型使用场景：

- 预览修完的图在普通笔记本、廉价便携屏、手机屏幕上观感；
- 模拟某台偏黄、偏蓝、饱和度偏低的显示器；
- 快速校验图片在色域不足设备上会不会艳度过爆；

> 
> 定位：观感仿真工具，**不是精确色度校准模拟器**（精确色度用 ICC 配置文件软打样）。

## 2. UI 面板与控件

新增独立面板：【设备模拟】，顶部总开关：`启用设备模拟`，关闭时所有参数失效、画布直通。
面板分组：

1. 基础观感参数（全部滑块，值域带数值输入框）
   - 亮度：`[-0.5 ~ +0.5]`，默认 0；线性增益偏移
   - 对比度：`[0.2 ~ 2.0]`，默认 1.0
   - 饱和度：`[0.0 ~ 2.0]`，默认 1.0；0 = 完全灰度单色
   - 伽马：`[0.5 ~ 3.0]`，默认 1.0；模拟显示器伽马偏差
2. RGB 色偏增益（模拟屏幕偏色）
   - R 增益：`[0.5 ~ 1.5]`，默认 1.0
   - G 增益：`[0.5 ~ 1.5]`，默认 1.0
   - B 增益：`[0.5 ~ 1.5]`，默认 1.0
3. 快捷预设组（一键载入参数，附带自定义保存）
   - 笔记本普通屏（默认预置：饱和度压低、轻微伽马偏移）
   - 手机屏幕（默认预置：饱和度偏高）
   - 老旧 TN 屏（对比度低、轻微黄偏）
   - 灰度预览（饱和度 = 0，其余默认）
   - 重置：全部参数恢复默认 1.0 / 0
   - 保存预设 / 删除自定义预设：持久化存在配置文件
4. 读数切换选项
   - 色彩取样读数来源：【原始图像（推荐）】 / 【模拟后画面】；默认原始图像，避免标定、校色读数被模拟层干扰
5. 视图标记提示
   - 开启模拟后，画布角落显示一个小标识「设备模拟已开启」，提醒用户当前画面不是原始效果，防止误判调色。

## 3. 变换计算顺序（固定）

输入：已经完成色彩管理、转换到本机显示器空间的像素 RGB（0~1，非线性，显示器编码空间）
变换顺序：

1. 亮度偏移：`rgb = rgb + brightness`
2. 对比度：`rgb = (rgb - 0.5) * contrast + 0.5`
3. RGB 通道增益：`R *= rGain; G *= gGain; B *= bGain`
4. 伽马映射：`rgb = pow(clamp(rgb, 0.0, 1.0), gamma)`
5. 饱和度调整：转到 sRGB 感知亮度，混合灰度与彩色
```
L = 0.2126*R + 0.7152*G + 0.0722*B
R = L + (R-L)*saturation
G = L + (G-L)*saturation
B = L + (B-L)*saturation
```
6. 全部结果钳位 `[0,1]`，防止溢出

> 
> 顺序理由：先明暗增益、再通道偏色、再伽马、最后饱和度，贴合普通人对屏幕偏差的感知。

## 4. 性能规则

- 开关切换、拖动参数：仅在画布纹理 / 帧缓冲层面做 2D 后处理，**不走 RAW 渲染管线，不触发去马赛克、色彩管线重算**，拖动实时低延迟；
- 支持降采样预览、1:1 视图，逻辑一致；
- 不写入导出：导出、复制参数、生成黄金样张、ΔE 基准计算，**永远使用未叠加设备模拟的原始渲染结果**。

## 5. 和 ICC 软打样的叠加规则（重要）

两个功能独立层，可以自由组合：

> 
> 主渲染管线 → ICC 软打样（可选，印刷 / 色域模拟） → 设备模拟（可选，观感偏差模拟） → 画布输出

- 仅 ICC：专业软打样
- 仅设备模拟：模拟屏幕观感
- 同时开启：先做 ICC 色域 / 纸白模拟，再叠加屏幕偏差
- 区分提示文案：ICC 软打样是【色彩空间合规模拟】；设备模拟是【显示设备观感偏差模拟】

## 6. 序列化

参数保存在软件全局首选项 / 视图配置，**不属于图片工程参数、不随 rawedit 工程保存**（这是视图浏览辅助，不是调色参数）

```
{
  "deviceSimEnable": false,
  "brightness": 0.0,
  "contrast": 1.0,
  "saturation": 1.0,
  "gamma": 1.0,
  "rGain": 1.0,
  "gGain": 1.0,
  "bGain": 1.0,
  "readSource": "original", // original / simulated
  "presets": [
    {
      "name": "普通笔记本屏",
      "brightness": 0.05,
      "contrast": 0.9,
      "saturation": 0.85,
      "gamma": 1.1,
      "rGain":1.02,
      "gGain":0.98,
      "bGain":0.97
    }
  ]
}
```

## 7. 验收标准

1. 总开关生效，关闭时画面直通，性能无损耗；开启后画布实时响应参数拖动；
2. 变换顺序符合定义，各项参数效果符合预期；参数超出范围自动钳位；
3. 快捷预设一键加载、自定义预设可以保存删除；重置功能正常；
4. 色彩取样读数可以切换原始 / 模拟画面，默认读取原始；
5. 开启状态画布有提示标识；导出图片、直方图基准、ΔE 计算不受模拟层影响；
6. 可与 ICC 软打样同时开启，叠加顺序正确；关闭 ICC 之后设备模拟单独正常工作；
7. 视图缩放、平移、1:1 切换，模拟效果持续稳定；
8. 参数持久化，重启软件保持上次开关和参数状态。
