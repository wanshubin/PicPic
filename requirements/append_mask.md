# 需求：亮度范围蒙版 + 颜色范围蒙版

> 
> 前置说明
> 
> 
> 1. 现有画笔 / 径向 / 线性蒙版已经开发完成，本需求为**新增两类并行蒙版类型，不替换原有蒙版**；
> 2. 复用整套蒙版框架：`MaskModel`、局部调整管线、蒙版权重缓存、tile 分块渲染、预览体系、序列化、图层叠加混合逻辑；
> 3. 管线位置：全局标定（基准白平衡、CCM 等）之后、上层基础调色之前，和其他局部蒙版处于同一渲染阶段；
> 4. 混合规则统一：同一局部调整层只能选择一类蒙版；多个局部调整图层自上而下叠加，权重相乘混合；
> 5. 蒙版计算空间约定：
>    - 亮度蒙版：在线性工作空间（ProPhotoRGB）计算亮度；
>    - 颜色范围蒙版：转到 Lab 空间做色相、饱和度筛选，降低明度干扰，色彩选择更稳定；

## 一、亮度范围蒙版（Luminance Mask）

### 1. 能力定义

依据像素**线性亮度值**生成 0~1 权重，只按明暗筛选像素，不受空间位置约束；适合压高光、抬阴影、校准中间调影调。支持区间控制、柔化过渡、反相。

> 
> 【亮度计算备注】
> 默认采用行业通用感知亮度公式：\(\boldsymbol{L = 0.2126*R + 0.7152*G + 0.0722*B}\)，输入为管线内线性工作空间 RGB；该系数源自 ITU-R BT.709 原色体系，用于和主流摄影后期软件蒙版行为对齐。
> 预留高级严谨模式开关（可选）：使用 ProPhotoRGB 原色对应的 XYZ-Y 物理亮度：\(\boldsymbol{Y_{ProPhoto}=0.2880402 R + 0.7118741 G + 0.0000857 B}\)，严格遵从 CIE 光度定义。

### 2. UI 与交互

新建蒙版下拉选项：`画笔 / 径向 / 线性 / 亮度范围 / 颜色范围`，选中后切换专属面板

1. 快捷预设按钮（一键加载区间）
   - 高光、阴影、中间调、重置
2. 直方图联动视图（线性亮度直方图）
   - 两个可拖拽控制点：下限 Low、上限 High
   - 柔化滑块：控制区间两侧衰减坡度，柔化越大过渡越平滑
   - 数值输入框：Low / High / 柔化，拖拽和数值双向同步，值域 [0,1] 自动钳位
3. 吸管拾取
   - 画布取点，自动以拾取亮度为区间中心，按当前柔化撑开区间
4. 通用蒙版控件（和其他蒙版统一）
   - 反相开关、蒙版密度；预览切换：红色叠加 / 黑白蒙版视图

### 3. 权重计算公式

```
像素落在 [Low, High] 内部：权重=1
靠近区间边缘按柔化做S型平滑衰减；区间外逐步降到0
开启反相：weight = 1 - weight
最终权重再乘以蒙版密度
```

### 4. 缓存 & 性能

- 修改 Low/High/ 柔化 / 反相 → 触发蒙版权重重算；只改该层调色参数（曝光、饱和度等）不重算蒙版
- 交互预览：使用降采样低分辨率快速生成蒙版；1:1 视图、导出全尺寸时使用原图分辨率计算
- 适配 tile 渲染，只更新变更 tile

### 5. 序列化

```
{
  "maskType": "luminance",
  "low": 0.04,
  "high": 0.88,
  "softness": 0.11,
  "invert": false,
  "density": 1.0,
  "luminanceMode": "bt709" // "bt709" / "prophotoY"
}
```

## 二、颜色范围蒙版（Color Range Mask）

### 1. 能力定义

基于 Lab 色彩空间的色相 H、饱和度 C 筛选像素，不受亮度强干扰；适合单独选中某一类色彩（例如色卡红色块、天空蓝色、绿植）单独校正，是色彩标定场景高频工具。

> 
> 设计取舍：以色相为主、饱和度为辅；明度通道仅做可选约束，默认关闭，避免和亮度蒙版功能重叠。

### 2. UI 与交互

1. 拾取模式（优先工作流）
   - 主吸管：点击画布拾取目标颜色，作为基准色
   - 加选吸管 / 减选吸管：多点采集，合并目标颜色集群
2. 控制滑块
   - 色相容差：色相允许偏差范围
   - 饱和度容差：饱和度允许偏差范围
   - 柔化：色彩边界过渡平滑度
   - 可选：明度范围开关 + Low/High 滑块（默认关闭，按需启用）
3. 色环可视化：显示基准色相、容差区间范围
4. 通用蒙版控件：反相、蒙版密度；预览切换：红色叠加 / 黑白蒙版视图

### 3. 权重逻辑

1. 像素 RGB 转 Lab，换算出色角 H、饱和度 C；
2. 计算当前像素和拾取基准色集群的色相距离、饱和度距离；
3. 在容差内权重趋近 1，超出容差后按柔化平滑衰减到 0；
4. 多拾取点：取所有基准点里的最大权重（只要匹配任意一个采集色就被选中）；
5. 反相、密度和亮度蒙版逻辑一致。

> 
> 注意：不要在 sRGB 做色相判断，Lab 下色彩筛选跨亮度更稳定，不容易受明暗影响误选。

### 4. 缓存 & 性能

- 修改拾取色、容差、柔化、明度约束、反相 → 重算权重图
- 同样支持降采样预览加速、tile 局部更新；全尺寸导出重新计算
- 拾取颜色集合存储为一组基准 Lab 点，不是固定 RGB，保证管线色彩空间切换时行为稳定

### 5. 序列化

```
{
  "maskType": "colorRange",
  "targetColors": [{"L": 62.1, "a": 18.3, "b": 4.2}],
  "hueTolerance": 22.0,
  "satTolerance": 18.0,
  "lightnessEnabled": false,
  "lightnessLow": 0.0,
  "lightnessHigh": 1.0,
  "softness": 0.08,
  "invert": false,
  "density": 1.0
}
```

## 三、统一验收标准（两类蒙版共用 + 各自专项）

### 通用验收

1. 蒙版列表可正常选择亮度范围、颜色范围；面板切换正常，原有画笔 / 径向 / 线性蒙版不受影响；
2. 蒙版预览（红叠 / 黑白）实时更新，拖动参数交互流畅；
3. 支持和其他类型蒙版分层叠加，混合权重行为统一；反相、密度生效；
4. 工程保存、加载、复制粘贴局部调整层，蒙版参数完整还原；
5. 缓存失效逻辑正确，不做多余全图重算；tile 渲染正常。

### 亮度蒙版专项

1. 支持两种亮度计算模式切换：BT.709 感知亮度 / ProPhoto 原生 CIE Y 亮度；默认 BT.709；
2. 直方图控制点、吸管、预设、数值输入双向同步。

### 颜色范围蒙版专项

1. 色彩筛选在 Lab 空间执行，同色相不同明暗的像素可以稳定选中；
2. 多点加选、减选功能正常；色环视图跟随基准色相更新；
3. 关闭明度约束时，亮度不干扰色彩选区。

## 四、UI 提示文案（直接放到面板顶部）

> 
> 亮度范围蒙版：按画面线性明暗自动选区，不限制位置，适合分区控制高光阴影。
> 计算模式：BT.709 感知亮度（默认）｜ProPhoto CIE Y（高级）
> 
> 
> 颜色范围蒙版：按色相 / 饱和度筛选色彩，适合单独校正某一类颜色（色卡、天空、植被等）。
