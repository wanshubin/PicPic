核心原则：

1. 所有传感器校正、伪色 / 色散修复，**全部在线性传感器 RGB 域执行，放在白平衡、CCM 之前**；转入标准 RGB 工作空间后不再做底层修复
2. 所有校正模块支持独立开关；内置【标定视图】一键关闭全部额外校正，输出原始解拜耳线性数据，用于 CCM 标定、色彩比对
3. 参数分层优先级：用户实时参数 > 镜头配置参数 > 机型默认参数 > 全局默认参数
4. 低分辨率交互预览、全尺寸导出复用同一套管线逻辑，滤波半径随分辨率自适应缩放，保证观感一致
5. 管线顺序严格固定，禁止随意调换节点顺序

# Phase 1｜第一阶段：基础还原闭环（必须优先完成，地基模块）

> 
> 阶段目标：解决最核心的解码缺陷，拿到稳定、色彩可信、彩边可控的 RAW 基底；完成后才具备调色基础
> 交付标准：打开 RAW，明暗基准正常、白平衡可控、机型色彩基准稳定、高光光斑 / 轮廓彩边大幅抑制；标定视图可输出纯净原始线性数据

## 1.1 RAW 线性解析模块

- 能力：基于 LibRaw 解析 CR2/CR3/NEF/ARW/RAF/SRW/DNG 等主流 RAW；识别 12/14/16bit 原始数据、压缩 / 非压缩 RAW
- 自动读取 RAW 内嵌黑电平 Black Level、饱和电平 White Level
- 将传感器原始信号归一化到稳定线性浮点值域
- UI：无交互控件（底层自动）；标定视图模式下保留原始数值不做偏移
- 约束：不做任何机内 JPEG 风格映射，输出传感器原生线性信号

## 1.2 Demosaic 解拜耳模块

- 算法选项：默认 AMaZE（平衡速度与伪色）；导出高质量模式 LMMSE；VNG 仅保留用于对比测试
- 内置 LibRaw FBDD 伪色 & 彩色噪点抑制；参数【FBDD 强度 0~1，默认 0.6】，独立开关
- UI：下拉框切换解拜耳算法；FBDD 强度滑块、独立开关
- 约束：标定视图自动关闭 FBDD

## 1.3 高光 Rolloff 软饱和压缩模块

> 
> 解决：R/G/B 通道不同步 ADC 饱和，高光点光源、灯串出现发散彩色光斑

- 算法：线性域拐点平滑压缩曲线，拒绝硬裁切；参数：高光拐点、压缩坡度
- 参数支持写入机型 JSON 配置，不同 CMOS 使用不同默认值
- UI：【高光软压缩】独立开关、拐点滑块、压缩强度滑块
- 约束：仅在线性域执行；完全死白无信息区域无法恢复色彩，仅抑制彩边

## 1.4 LCA 横向色差校正模块

> 
> 解决：镜头色散带来画面四角、物体边缘红 / 青边

- 算法：以 G 通道为基准，R、B 通道亚像素缩放；支持径向渐变增强（边缘色散自动加强）
- 参数：红通道缩放、蓝通道缩放、径向增强强度（-0.008 ~ +0.008）
- 参数可保存至独立镜头配置文件
- UI：【横向色差校正】独立开关、3 个调节滑块

## 1.5 边缘导向伪色抑制模块（核心收尾）

> 
> 解决：Demosaic 插值残留紧贴高反差轮廓的成对红↔青、洋红↔绿毛刺伪色

- 算法：G 通道 Sobel 梯度生成边缘掩码；仅在高梯度边缘区域，对 R/B 通道做小半径中值平滑；G 通道全程不动，保护亮度细节、对比度；平坦区域完全不处理
- 参数：伪色抑制强度 0~1、边缘敏感度阈值、平滑半径
- UI：【边缘伪色消除】独立开关、强度滑块、边缘敏感度滑块；默认开启 0.5

## 1.6 白平衡模块

- 能力：色温 / 色调手动调节、灰卡取点采样、自动白平衡；在线性传感器域执行缩放
- 预置相机机型默认白点基准
- UI：色温滑块、色调滑块、取色器吸管、自动白平衡按钮
- 约束：白平衡在校正之后、CCM 之前；区分底层白平衡还原，不和后期创意色温混在一起

## 1.7 机型 CCM 色彩标定模块（色彩还原核心）

- 能力：基于相机 Make+Model 加载独立 3×3 CCM 标定矩阵；找不到机型时加载通用兜底矩阵
- JSON 结构存储：ccm_matrix、white_point、配套默认校正参数组
- 支持用户手动微调矩阵系数
- UI：CCM 模式切换（机型标定 / 通用 / 手动自定义矩阵）
- 约束：CCM 只负责还原真实色彩，不做风格化调色；标定视图可以跳过 CCM

## Phase1 交付验收清单

- RAW 正常读取、线性归一化，黑 / 白电平识别正确
- AMaZE 默认解拜耳，FBDD 可调可控
- 高光软压缩，高光彩边明显改善
- LCA 横向色差校正
- 边缘伪色抑制，高反差轮廓毛刺消除
- 多模式白平衡，采样取灰正常
- 机型 CCM 自动匹配，色彩基准稳定
- 标定视图一键关闭全部校正链路，输出原始线性图像
- 拖动低分辨率预览、全尺寸渲染管线一致

# Phase 2｜第二阶段：成像质感增强（Phase1 稳定后开发）

> 
> 阶段目标：补齐传感器物理缺陷补偿、镜头校正、噪点与细节控制，让 RAW 干净通透，专业度对标主流 RAW 软件基底

## 2.1 坏像素修复模块

- 识别热像素、固定死像素；邻域有效像素插值修复
- UI：【坏像素修复】独立开关；默认开启
- 进阶预留：支持导入暗场帧做坏像素映射（二期扩展）

## 2.2 暗电流补偿模块

- 按 ISO 分段设置暗电平偏移补偿，抑制高 ISO、长曝光暗部彩色底噪
- 参数随机型配置携带
- UI：【暗电流补偿】开关、补偿强度滑块

## 2.3 镜头渐晕校正模块

- 径向亮度补偿模型，校正镜头原生四角暗角；参数：强度、中心偏移、圆度
- 参数可存入镜头配置，镜头参数优先级高于机型默认
- UI：【渐晕校正】开关、强度滑块

## 2.4 CMOS 像素串扰补偿 Crosstalk

> 
> 解决 BSI 堆栈高像素 CMOS 微透镜光子渗漏，通道互相污染，高光容易串色

- 算法：3×3 解耦矩阵，放在 Demosaic 之前；大部分机型默认单位矩阵不生效
- 参数随机型标定 JSON 写入，强度 0~1
- UI：【串扰补偿】开关、强度滑块，默认开启
- 约束：饱和高光区域矩阵失效，交给高光 rolloff 处理

## 2.5 LoCA 轴向色差校正

> 
> 解决焦外散景、点光源光斑自带红 / 蓝色环（LCA 无法处理的纵向色散）

- 算法：DoG 差分提取高光光斑掩码，区分焦内 / 焦外，针对性衰减 R/B 色散分量，不破坏锐利边缘
- 参数：LoCA 强度、光斑阈值
- UI：【轴向色散校正】开关、强度滑块，默认 0.4

## 2.6 阴影线性提升模块

- 在线性域抬升阴影信号，附带噪声保护逻辑，避免暗部噪点同步爆炸
- 不破坏黑位，不提前做非线性映射
- UI：【阴影提升】开关、提升强度滑块

## 2.7 基础降噪模块

- 分为亮度降噪、彩色降噪两个通道；彩色降噪优先，保护边缘
- 根据照片 ISO 自动推荐初始降噪强度
- UI：【降噪】开关、亮度降噪滑块、彩色降噪滑块

## 2.8 边缘导向基础锐化模块

- 降噪之后执行；基于梯度掩码，只锐化边缘，不对平坦噪点区域增强
- 参数：锐化强度、半径、阈值
- UI：【锐化】开关、强度、阈值滑块

> 
> 约束：禁止放在降噪前面，防止放大噪点

## 2.9 镜头配置文件支持

- 独立 JSON 镜头配置，存储渐晕、LCA、LoCA 默认参数；优先级高于机型默认
- 预留 LCP 镜头配置文件解析接口（二期扩展）

## Phase2 交付验收清单

- 坏像素、暗电流补偿，高 ISO 暗部更干净
- 渐晕校正，暗角可控
- 串扰补偿，高像素 CMOS 高光串色改善
- LoCA 校正，灯光散景彩环抑制
- 阴影线性提亮，噪点可控
- 降噪 + 边缘锐化，细节干净不脏
- 镜头配置独立存储加载

# 全局公共需求（所有阶段生效）

## 参数存储体系

1. 机型配置 JSON：存放 CCM 矩阵 + 整套校正默认参数（串扰、FBDD、高光 rolloff、LCA、LoCA、伪色抑制等）
2. 镜头配置 JSON：存放镜头专属 LCA、LoCA、渐晕参数
3. 照片 Sidecar：存储用户实时调节的全部参数，和 RAW 同目录保存

## UI 通用规则

1. 设置面板分组：【传感器校正】【解拜耳与伪色】【镜头校正】【白平衡 & 色彩还原】【高光阴影】【降噪锐化】【调色】
2. 顶部视图切换：「观感预览」「标定视图」一键切换
3. 所有滑块支持数值输入框、重置默认按钮
4. 支持参数重置为机型 / 镜头默认值

## 打包 & 构建

- CMake 自适应 vcpkg 三元组，支持 `x64-windows`（动态 DLL + windeployqt）、`x64-windows-static`（静态单 exe）两套构建命令
- 不硬编码编译模式，开发调试用动态、发布可选静态

## ICC 色彩管理

- lcms2 代码内生成标准 RGB 工作空间 ICC（ProPhotoRGB/sRGB/AdobeRGB），不打包外部 icc 资源
- 显示器 ICC 自动读取系统，用于软校样

## 预览性能策略

- 交互拖动：拜耳域下采样 → 走完整管线渲染低分辨率预览，保证管线逻辑一致
- 鼠标松开 / 参数确认：触发全尺寸渲染
- 渲染缓存：参数不变时复用渲染结果，不重复计算
